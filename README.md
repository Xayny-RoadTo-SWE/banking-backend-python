# Banking Backend (Python)

A simple banking backend system built with **Python** and **MySQL**, designed to demonstrate core backend concepts such as:

- Database connections
- Transactions
- Error handling
- Clean CLI flow

## Features
- Create users
- Check balance
- Deposit funds
- Withdraw funds
- Transfer money between users (transaction-safe)

## Tech Stack
- Python 3
- MySQL
- PyMySQL
- CLI-based interface

## Notes
This project was built for learning and demonstration purposes, focusing on backend logic rather than UI.
